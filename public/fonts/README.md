# ฟอนต์ไทยสำหรับฝังลง PDF

วางไฟล์สองไฟล์นี้ในโฟลเดอร์นี้:

- `Sarabun-Regular.ttf`
- `Sarabun-Bold.ttf`

ดาวน์โหลดจาก https://fonts.google.com/specimen/Sarabun (สัญญาอนุญาต SIL OFL —
นำมาแจกจ่ายพร้อมเว็บไซต์ได้)

## ทำไมต้องโฮสต์เอง

1. **ทำให้ PDF ที่สร้างใหม่ค้นหาข้อความได้** — `lib/pdf/compose.ts` ฝังฟอนต์นี้
   เป็นชั้นข้อความโปร่งใสใต้ภาพ ทำให้ผลลัพธ์จากทุกเครื่องมือ "X เป็น PDF"
   และจาก OCR คัดลอก ค้นหา และให้โปรแกรมอ่านหน้าจออ่านได้
2. **ทำให้คำสัญญาเรื่องความเป็นส่วนตัวเป็นจริง** — การเรียกฟอนต์จาก
   Google Fonts คือคำขอเครือข่ายที่ส่ง IP ของผู้ใช้ไปให้บุคคลที่สาม
   ซึ่งขัดกับจุดขายหลักของเว็บนี้ (และเป็นปัญหาตาม GDPR ในสหภาพยุโรป)

ถ้ายังไม่ได้วางไฟล์ ระบบจะยังทำงานได้ปกติ เพียงแต่ PDF ที่สร้างจะไม่มีชั้นข้อความ
ที่ค้นหาได้ (`tryEmbedThaiFonts` จะคืน `null` แทนที่จะทำให้ทั้งงานล้มเหลว)
